# Frankie Yu Portfolio

Frankie Yu（俞伊倩）的个人作品集网站，使用 React、TypeScript 和 Vite 构建。

## 本地运行

需要先安装 Node.js。

1. 在项目文件夹中打开终端。
2. 安装依赖：

   ```bash
   npm install
   ```

3. 启动网站：

   ```bash
   npm run dev
   ```

4. 在浏览器打开终端显示的地址，通常是：

   ```text
   http://localhost:3000/
   ```

## 检查与构建

```bash
npm run lint
npm run build
```

视频、封面、分镜图和其他作品素材都放在 `public/` 文件夹中。项目默认中文显示，也保留中英文切换、六个栏目、红黑色视觉风格及 Storyboard 页面。
